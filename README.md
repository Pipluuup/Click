# 字母随机连发器（GUI 版）

一个带界面的小工具：点击「开始」后全局监听键盘，按下任意英文字母键时，吞掉原按键，把英文 **26 个大写字母（含被按下的那个）按随机顺序**，以模拟键盘输入的方式"打"到当前焦点窗口。点击「停止」恢复为正常输入。

## 安装

```bash
pip install keyboard
```

## 运行

```bash
python main.py
```

弹出一个小窗口，点击「**开始**」即生效，把焦点切到记事本等可输入文字的窗口，按任意字母键即可看到效果。

## 操作说明

| 操作 | 效果 |
|---|---|
| 点击「开始」 | 开始监听，全局吞掉字母键并随机打出 26 个大写字母（每次乱序不同） |
| 点击「停止」 | 停止监听，字母键恢复正常输入 |
| 全局按 F12 | 快速停止（不依赖切回窗口，此时 F12 不会触发浏览器开发者工具） |
| 关闭窗口 | 停止监听并退出程序 |
| 按住字母不放 | 只触发一次，不连发 |
| 按非字母键 | 正常放行，不触发 |

## 说明

- 开始监听期间，26 个字母键被全局吞掉，**无法正常打字母**，请用「停止」按钮或 F12 恢复。
- 模拟输入对普通应用（记事本、浏览器、编辑框等）有效；对使用 DirectInput / RAW INPUT 且拒绝模拟输入的少数程序（部分游戏）可能无效。
- 若触发瞬间正物理按住 Shift/Ctrl 等修饰键，注入的 Shift 序列可能产生少量冲突（罕见）。
- 依赖：tkinter（Python 自带）与 `keyboard`（见 requirements.txt）。
